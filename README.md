# Rekap Nilai Mahasiswa

Website Rekap Nilai Mahasiswa dibuat menggunakan PHP dan MySQL untuk memenuhi tugas praktikum Pemrograman Web.

## Fitur
- Menampilkan data mahasiswa
- Menambahkan data mahasiswa
- Mengubah dan menghapus data mahasiswa
- Mencari data mahasiswa berdasarkan nama
- Memfilter data berdasarkan predikat
- Mengurutkan nilai mahasiswa
- Pagination untuk membatasi jumlah data per halaman

## Teknologi
- PHP
- MySQL
- HTML dan CSS
- AdminLTE 4
- Bootstrap

## Cara Menjalankan
1. Jalankan Apache dan MySQL melalui XAMPP.
2. Letakkan folder project di dalam direktori `htdocs`.
3. Buka phpMyAdmin.
4. Buat database dengan nama `db5d`.
5. Impor file `db5d.sql`.
6. Periksa konfigurasi koneksi pada file `koneksi.php`.
7. Buka aplikasi melalui browser di alamat berikut:

   `http://localhost/Rekap-Nilai-Mahasiswa/adminlte/dist/users.php`

## Database
File database tersedia pada `db5d.sql`.
